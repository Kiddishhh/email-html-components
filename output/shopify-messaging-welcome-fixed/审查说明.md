# Shopify Messaging 变量修复

以用户本次完整拼接代码为基础，仅改两处：
- 将 Omnisend 的退订 anchor 替换为居中 span 内直接输出 {{ unsubscribe_link }}，保留原字体声明，不嵌套链接。实际链接 HTML 与文案由 Shopify 生成。
- 将最后一个页脚空 p 替换为 {{ open_tracking_block }}，不加 escape，不用隐藏容器包裹。

官方文档正文称 open_tracking，示例使用 open_tracking_block；本次遵从编辑器明确提示及官方示例，未重复加入 open_tracking。

静态校验通过：两个变量各一次，无 Omnisend 退订占位符，表格和 a/span 标签闭合；除退订 href 外原始 href/src/background 全部保持；两项改动还原后逐字等于输入；整封邮件小于500KB。

整体复制 HTML 到 Code your own 编辑器替换原代码。尚未实测 Shopify 校验提示或发送；普通浏览器不能验证退订和打开跟踪。
