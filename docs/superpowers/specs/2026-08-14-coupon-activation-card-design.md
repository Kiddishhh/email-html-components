# Coupon Activation Card 设计

## 目标

将参考稿实现为可粘贴到 Omnisend 的邮件安全优惠券组件。组件呈现为居中的轻奢礼券，不依赖 JavaScript、外部 CSS 或图片；`Activate >>` 为可配置链接。

## 画布与结构

- 内容本体为 `190 × 43px`，外层虚线框收紧至 `206 × 59px`，四周留白一致。
- 外层使用一像素深棕短虚线和无填充背景；最外层全宽表格只承担水平居中。
- 内层由左侧 `Coupon` 标签和右侧可点击按钮组成。标签不包含链接，按钮独占链接热区。

## 视觉规范

- 标签色：`#252321`；字体为 Montserrat/Arial 回退，15px、700 字重。
- 按钮色：`#A71E22`；白色文字，15px、700 字重。
- 按钮高 31px、圆角 5px；文字垂直居中，按钮周围保留平衡的留白。
- 外框与正文之间不使用过大的空白，确保其仍读作一张礼券而非松散的两段文本。

## 邮件兼容性

- 使用嵌套的 presentation table、HTML `align` 属性和内联 CSS。
- 同时保留 `bgcolor` 作为按钮背景回退；圆角在不支持的客户端可退化为直角按钮。
- 不使用 Flex、Grid、脚本或外部字体。链接默认使用 `https://freshinelife.com/`，可直接替换 `href`。
