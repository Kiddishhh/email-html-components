# Freshine single-coupon component

Copy component.html in full. It contains only the email component, with no footer, unsubscribe or document wrapper. Its backgrounds are scoped to the component.

index.html is a local preview with fonts loaded. Do not copy compare.html. If the host email has not already loaded Lora/Montserrat, put fonts.css contents in a style tag inside its head; unsupported email clients use fallbacks.

Uses original CDN logo and new 2279.png coupon background. All coupon text remains editable. CTA uses https://freshinelife.com?utm_source=shopify-flow&utm_medium=email&utm_id=cover-rc . No clipboard interaction, automatic discount application or backend discount configuration is included.

Typography and casing follow the prior approved component. 600px desktop / 375px at 62.5%, except 1px borders per component contract. See design-qa.md for local checks and inbox limitations.
