# 双赠品奖励卡上下布局设计

## 目标

把 `gift.rewardGrid2` 从左右双列改成邮件安全的上下单列结构，视觉以 `/Users/ww/Downloads/赠品版块/上下I.png` 为唯一参考，同时保留 V1 文件契约和 componentKey，避免影响后续 Skill 的组件识别。

## 内容边界

- 可编辑：顶部标题、两条活动规则、上图 URL/alt/跳转链接、下图 URL/alt/跳转链接。
- 可替换样式：组件背景色 `color.surface`；标题和正文颜色、字体及常用间距继续保留为高级设置。
- 不可编辑：图片内部的价格、赠品名称和说明；这些内容属于图片本身，换活动时整体替换图片。
- 默认顺序：上图为枕套赠品，下图为眼罩赠品。

## 结构与兼容性

组件使用单根 100% 表格，标题区下方依次放置两个 100% 流式图片链接，中间仅保留 4px 间距。模板不使用文档级标签、`div`、脚本、外部 CSS、Flex/Grid、定位或背景图片；图片显式声明宽高并用 `width:100%;height:auto` 流式缩放，因此在 600px 桌面画布和 375px 移动端都保持单列。

## Skill 采集规则

Skill 默认询问顶部三段文案、上下两张完整图片、两张图片的目标链接及背景色。图片必须在生成 Omnisend HTML 前转换为公开 HTTPS URL；本地演示允许引用组件目录内的参考裁切图。

## 验收

- 静态模板符合根目录 Omnisend 安全导入规范。
- 内容和设置 Schema 明确标注 Skill 采集字段。
- `效果演示.html` 无模板占位符，使用默认文案和本地参考图片。
- 浏览器分别检查 600px 与 375px，不得横向溢出。
