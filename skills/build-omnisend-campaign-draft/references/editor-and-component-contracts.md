# 已有编辑器与组件行为契约

这些细节用于维护现有应用和已确认组件；制作邮件时按需查询，不将历史组件优惠当作当前活动事实。组件入口与字段以实时注册表、Schema和管理说明为准。

## Current editor capabilities

- Free composition from all registered components: add, repeat, drag-sort, select, edit, confirm, and delete.
- Named local templates: save the current complete snapshot, select a template to create a new editable draft, overwrite only after confirmation, and delete the template together with its dedicated local-image copies.
- Local image upload and preview exist only for the current editor run. Saving a template copies its selected local images into that template's dedicated asset directory; component-directory assets are never copied or deleted.
- Desktop/mobile preview switching and selected-component positioning.
- `navigation.visible` toggle for the four navigation-capable head-image styles. When disabled, the navigation markup and its height are removed from generated HTML while the saved copy, URL, and colors remain available for re-enabling.
- Shopify read-only import for the six-product grid, registered four-product grid styles (one selected product per card), and the two single-curtain promotion cards. The navigation promotion CTA is text, color, divider-image, and CTA-link only.
- `collection.productGrid4NoSidePadding` is the independent full-width four-product layout: 600px with 289×361px cards and a 22px gutter. Its four Shopify imports update only the selected card, including its CTA text.
- Runtime-only Omnisend API Key dialogs with show/hide support. Keys are cleared after success, failure, or cancellation and are never written to drafts, files, parameters, environment variables, logs, or chat.

## Per-copy text styles

- For typography/spacing requests in the local editor, use the selected field’s “文字样式” controls. Read [text-style-controls.zh-CN.md](text-style-controls.zh-CN.md) for scope, dimensions and the optional `textStyles` contract.
- Editor default font stacks are exactly `Georgia,serif` for title/heading/headline fields, product card titles `product.name`, and grid product titles `saleItems[n].name`; other copy uses `Verdana,sans-serif`. The optional Composition `fontDefaults: "georgia-verdana"` applies this before explicit per-field overrides; resetting a font returns to this policy. Raw component templates remain unchanged.
- Overrides belong to the selected instance and content field, travel through the serial save queue and templates, and invalidate confirmation. Do not rewrite component defaults or migrate typography in other components.
- Leave unmodified properties inherited. Clearing a property restores that property; resetting the field stores an empty object. Preserve content, assets, URLs/UTM, horizontal spacing and independent spacer rows.
- Use only bounded values and font stacks from the shared contract. Emit desktop px fallbacks and proportional inline mobile dimensions, with no external font dependency or editor UI markup. Check the selected field at 600px and 375px; local preview does not prove real inbox rendering.

## Editor round 1 controls

- Component instances use per-draft monotonically increasing counters; deleting and re-adding a repeated style must never collide with another live instance. Old drafts without counters derive the next suffix from existing IDs.
- Search the catalog by Chinese name, category, componentKey or variant. Thumbnail cards are sandboxed, lazy-loaded default-component previews rendered by the existing email builder and cached for the current server session. Select a card, then use “添加此组件”; existing structure/style selectors remain available.
- Product arrays are grouped into collapsible “顶部文案”, “商品 1–6”, “底部 CTA” panels; each supported per-card importer stays beside that card's fields. Grouping never adds editable fields or changes component HTML/CSS.
- Saves are bound to their originating draft, serialized and show pending/saving/saved/failed status. Structural/draft/import/output operations temporarily protect the editor while their request is pending; ordinary autosaving allows continued typing. New input overlays older responses. Failed patches remain queued; use “重试保存”. Selection, confirmation, imports, structural changes, template use/save and output actions wait for pending saves. “已保存” means current-session storage, not durable cross-restart storage.
- “链接 / UTM” reads actual rendered anchors and maps them from the source href field (never URL equality), including fixed footer/unsubscribe links and excluding hidden navigation. Fixed or non-HTTPS links cannot receive bulk UTM changes. Editable links offer field positioning.
- UTM parameters are applied only to explicitly selected editable HTTPS links, after “预览 UTM 修改” and “应用已预览修改”. Preserve non-UTM query parameters and fragments; blank UTM inputs preserve existing values. Shared image/CTA fields change together. Canceling the dialog makes no content change. Changed components require confirmation again.
- Editor iframes, controls, search, groups and links panels must never be included in exported email. Keep the existing Omnisend safe builder, public HTTPS image resolution, unsubscribe token, draft-only upload/readback and 600px/375px proportional inline CSS contracts. Local/browser evidence does not prove Omnisend or inbox rendering.
