# 场景文字叠层头图2设计

## 目标

新增可复用的 `场景文字叠层头图2`，以用户提供的 Labor Day Sale HTML 为已确认视觉来源，并使其能在本地 HTML 编辑器中添加、编辑、预览和导出。

## 组件边界

- 中文名：`场景文字叠层头图2`
- componentKey：`hero.sceneOverlayCta2`
- 分类：`头图`
- 桌面画布：600px 宽，由 56px 双色导航和 632px 场景头图组成。
- 移动目标：375px；所有固定的可见尺寸按 62.5% 通过 inline `min()` 规则等比收缩。
- 使用表格、内联 CSS、图片和链接；不使用 JavaScript、Flex、Grid、定位或跨组件样式。

## 可编辑契约

内容字段：

- 导航左侧促销文案。
- 导航右侧 CTA 文案与 HTTPS 链接。
- 首图背景 URL、Alt 与整图 HTTPS 链接。
- Logo URL 与 Alt。
- 活动名称、主优惠、补充说明。

设置字段：

- 导航显示开关。
- 导航左右背景色、导航文字色、首图兜底色、叠层文字色。

不开放几何、字体、渐变叠层、Logo/文案位置或缩放开关。

## 默认内容与链接

默认值沿用已提供的 Labor Day Sale 文案、Omnisend 公开背景与 Logo URL，并保留原始 `cover-fc` UTM 跳转链接。组件目录保存本地预览素材，fixture 使用 `asset://`；导出时仍需通过既有确认流程解析为公开 HTTPS 资源。
