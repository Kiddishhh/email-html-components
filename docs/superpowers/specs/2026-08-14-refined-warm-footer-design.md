# 精致暖棕页脚设计

## 目标

在不改动现有品牌、地址、电话、支持邮箱、社媒链接和 Omnisend 退订令牌的前提下，重排 `footer.warm` 的视觉层级，使其在 600px 桌面宽度和窄屏邮件中清晰、紧凑且易读。

## 布局

- 外层保持暖棕 `#652A0D` 背景和单根 presentation table。
- 内容宽度由 382px 增至 440px；外层采用 24px 水平、32px 垂直留白。
- 品牌名独立置顶，使用 17px 半粗文字；地址与联系信息为 13px、20px 行高的连续信息组。
- 免责声明单独成段，使用 11px、17px 行高，避免与地址和电话混读。
- 社媒图标独立成组，24px 图标之间使用 10px 间距；版权与退订链接置底并使用 11px 辅助文字。

## 可访问性与邮件兼容

- 所有布局使用 table、tr、td 与内联 CSS；不使用 div、外部 CSS、JavaScript、Flex 或 Grid。
- 文字与链接维持白色系，链接使用高对比浅金色 `#F4D8A7`，并以 underline 指示可点击性。
- 图片继续保留原有 alt 文本、显式 24px 尺寸和既有外部链接。
- `[[unsubscribe_link]]` 必须原样保留，且只用于退订链接的 href。
