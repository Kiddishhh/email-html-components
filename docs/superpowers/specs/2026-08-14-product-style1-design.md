# 小样产品样式1设计

## 目标

新增一个独立、可复用的 Omnisend 邮件产品展示组件，视觉参考 `样式IX.png`：大幅主图、左下文案与 CTA，以及覆盖右下区域的小幅材质图。组件先以通用目录形式维护，待用户确认视觉样式后再注册到 Campaign Skill。

## 范围与边界

- 新目录为 `小样/产品/样式1/`；中文名为“产品样式1”，组件键为 `product.sampleStyle1`。
- 本次加入 `组件清单.json` 的通用组件清单和 `组件索引.md`，但不修改 Campaign 的六个固定区段、候选项或交互索引。
- 不创建 Omnisend 草稿、不上传图片、不发送或排期。
- 正式邮件 HTML 保持单根表格、内联 CSS、600px 容器，且不使用 JavaScript、`div`、Flex/Grid、绝对定位或外部样式表。

## 内容接口

组件采用完整快照和 `full-component-rerender` 注入模式。必填内容字段如下：

| 字段 | 用途 | 本地预览 |
| --- | --- | --- |
| `product.mainImage.url` | 主视觉图片 URL | 支持 `asset://` |
| `product.mainImage.alt` | 主图替代文本 | 不适用 |
| `product.detailImage.url` | 右下叠加小图 URL | 支持 `asset://` |
| `product.detailImage.alt` | 小图替代文本 | 不适用 |
| `product.title` | 产品标题 | 不适用 |
| `product.subtitle` | 产品副标题 | 不适用 |
| `product.cta.text` | 按钮文案，默认 `SHOP NOW` | 不适用 |
| `product.cta.url` | CTA 目标地址，必须为绝对 HTTPS URL | 不适用 |

图片字段标记为 `image-source` 且要求 HTTPS。拼接器现有的资产机制允许这两个字段在预览时使用已注册的本地 `asset://` 资源；最终构建仍由既有固定上传流程将其转换为公开 HTTPS 图片。因为尚未注册 Campaign Skill，本次不会新增任何 Skill 注入阶段。

## 版式与降级策略

组件使用暖白色 `#F8F5F1` 底色，外层最大宽度固定为 600px。在桌面邮箱中，主图使用约 548px 内容宽度；文案占下方左侧区域，小图约 205px 宽，以负上边距叠到主图右下。阴影由一层右侧和底部留白的灰褐色表格底板实现，不使用会被项目安全验证器阻断的 `box-shadow`。

表格结构同时提供无增强降级：若客户端忽略负边距或阴影，小图自然落在文案右侧，不会遮挡标题、按钮或主图。组件不依赖阴影、叠加或圆角来传递文本、图片或点击能力。效果演示页以 600px 桌面画布呈现，并提供 375px 的同宽缩放检查环境。

## 设置接口

设置是组件拥有的完整快照，默认值固定参考稿的比例与颜色：表面色、内容宽度、主图宽度、小图宽度、小图叠加距离、CTA 边框色、标题色、副标题色和阴影色。字体使用 `Arial, Helvetica, sans-serif`；不会引入网络字体。

## 文件与验证

目录将包含模板、内联样式来源、内容与设置 Schema、默认 fixture/defaults、默认预览素材、中文管理说明及该目录自身的 `效果演示.html`。回归测试覆盖：注册表路径、必填可编辑字段、600px/375px 几何设置、本地两图片资产的预览解析、组件不进入 Campaign 固定候选，以及邮件安全叠加降级结构。

## 验收条件

1. `小样/产品/样式1/效果演示.html` 能直接展示设计稿风格的完整组件。
2. 主图、小图、标题、副标题、CTA 文案与链接均能由内容快照替换。
3. 两张本地图片可通过登记的 `asset://` 资源用于本地预览，最终 HTML 仍拒绝未上传的本地资源。
4. 在 600px 画布中小图视觉上覆盖主图右下并带阴影；在 375px 画布中内容仍可读、CTA 可点击。
5. 所有现有测试以及新增回归测试通过，静态安全检查不引入邮件禁止结构。
