# 倒计时头图2 组件管理说明

## 用途

`hero.countdownOverlay2` 是 600px 邮件首图样式，保留 Logo、顶部促销条、三行活动文案、主图和图下促销信息区。`ONLY 3 DAYS!` 是可编辑静态文案，不是实时倒计时。

默认 Logo 使用透明底深棕色 FreShine 字标，默认色取自确认参考图的 `#652E17`；Logo 区继续使用组件整体背景色，不新增独立色块。

## HTML 输出

- `component.template.v1.html` 是供拼接器注入完整 `content` 与 `settings` 快照的邮件安全 HTML 组件片段，保留 `{{content.*}}` 与 `{{settings.*}}` 占位符。
- `效果演示.html` 是已注入默认完整快照、CSS 已内联且可直接在浏览器打开的完整本地预览 HTML；它是样式选择和组件验收的正式演示文件。
- 截图只用于记录 600px 与约 375px 的视觉验收结果，不是组件交付文件，也不得代替上述 HTML。

## 顶部导航栏开关

可视化编辑器以“显示顶部导航栏”复选框开放 `navigation.visible`，默认值为 `true`。关闭后，构建器会从最终 HTML 中完整移除 Logo 下方的促销导航及其占位高度；顶部 Logo、主图、活动文案、权益区和 CTA 保持不变。导航文案、链接和颜色仍保存在当前组件快照中，重新开启即可恢复。不得用 CSS `display:none` 模拟隐藏。

促销导航栏对齐夏末折扣促销首图：左侧 `75.5%`、右侧 `24.5%`；桌面高度 `71px`，移动端采用 `min(71px,11.833333vw)`。促销文案和 `SIGN UP` 都使用 Montserrat Regular `18px / 24px` 并随移动宽度缩小，右侧链接保持下划线；现有左右背景色保持可编辑。

## 固定布局

- 桌面画布最大宽度 600px，移动端流式缩放到约 375px。
- Logo 位于邮件组件的最顶端、导航栏之前；其独立 64px 区域使用原生 `height` 属性与 `valign="middle"`，并通过可配置的 `logo.offsetTop`（默认 `4px`）让字标视觉中心略低于严格几何居中位置，而不改变导航栏位置。
- 主图固定使用 `1:1` 比例，并与下方促销信息区组成宽度 90%、最大 540px 的内层卡片；桌面端主图显示为 `540×540px`，约 375px 移动端显示为 `337.5×337.5px`；建议原图 `1200×1200px`。
- 内层卡片置于组件整体背景色之上，保留左右和 18px 底部背景留白；主图与下方促销信息区严格等宽。
- `ONLY 3 DAYS!` 固定使用 Lora Medium（500）、28px / 36px、1px 字间距；三项权益之间固定显示两条竖向分隔线。
- CTA 使用 Montserrat 18px / 400，49px 高；按钮宽度随文案自然收缩，并通过可配置的左右内边距保持视觉留白。
- 顶部促销栏及 `SIGN UP` 使用与夏末折扣促销首图一致的 Montserrat Regular `18px / 24px` 流式规格，桌面基准高度为 71px；主标题下补充说明使用 14px/21px，底部补充提示使用 14px/20px；三项权益使用 Montserrat SemiBold（600）12px/15px、居中对齐，避免移动端三栏过度换行。
- 三项权益数量与顺序固定；桌面端和移动端都保持三栏。
- 权益文案建议不超过 24 个英文字符；超长时只提示移动端风险，不自动截断。

## 内容注入

- `hero.eyebrow`、`hero.title`、`hero.subtitle` 由 Skill 沿用 Shopify 首页 slide 活动快照映射。
- `hero.cta.url` 由 Skill 写入当前选定活动页 URL。
- 主图必须主动收集；可使用默认裁切图、用户本地图或公开 HTTPS 图片。
- 比例不符时运行 `prepare-countdown-hero-2-image.mjs`，生成独立居中裁切衍生图，不覆盖原图。
- 本地 `asset://` 只能用于预览；最终 Omnisend HTML 必须替换为公开 HTTPS URL。

## 颜色

- `color.theme` 同时控制 CTA 操作色，可继承 Campaign 全局操作色。
- `color.surface` 用于 Logo 区和活动文案区，可继承正文背景色。
- `color.offerSurface` 是图下促销文案区的组件默认色，不自动继承全局正文背景色。
- 顶部促销条左右色块默认保持设计色，只在用户主动提出时修改。

## 预览与确认

完成卡片展示全部文案、Logo、主图、Alt、链接、三项权益、颜色和资产来源，并同时生成 600px 桌面端和约 375px 移动端预览。只进行一次组件完成确认；用户主动提出修改时，只更新指定字段并刷新同一组卡片与预览。确认后由拼接器输出完整 HTML，组件截图仅保留为验收证据。
