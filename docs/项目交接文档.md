# Freshine 邮件项目交接说明

## 项目功能

- **拼装邮件**：提供头图、商品推荐、评论、赠品、页脚等组件，可以自由组合成一封邮件。
- **可视化编辑**：在编辑器里修改文案、图片、颜色、链接和组件顺序，同时查看电脑和手机效果。
- **制作和修改组件**：把参考图或 HTML 交给 Agent，制作成适配 **600px 桌面端和 375px 移动端**的可复用邮件组件，也可以调整已有组件。
- **辅助写文案**：告诉 Agent 活动主题和优惠信息，让它推荐邮件主题和副标题。
- **Shopify 一键导入商品**：支持导入的活动商品组件可以从 Shopify 一键导入商品图片、标题、价格等信息，减少手动填写；导入只读取信息，不修改店铺商品。
- **复用邮件模板**：做好的邮件可以保存成模板，下次活动直接复用和修改。
- **输出邮件**：导出适用于 Omnisend 的 HTML，或上传为 Omnisend 草稿，后续在平台检查和发送。

## 使用方法

1. **拉取整个项目文件夹**，放到本地，并在 Agent 中打开。组件、素材、脚本和文档都要保留，不能只拿 Skill 文件。
2. **注册文件夹中的 Skill**。它的位置是 `skills/build-omnisend-campaign-draft`，可以直接让 Agent 帮忙注册：

   > 请把当前项目中的 skills/build-omnisend-campaign-draft 注册为可用 Skill，保留它与项目文件夹的关联，并确认能读取项目文件、运行邮件编辑器。

3. **直接向 Agent 提需求**。可以在需求前加上“使用 $build-omnisend-campaign-draft”，让它按这个项目的流程处理。

## 怎么提需求，能得到什么

| 对 Agent 说 | 能实现的效果 |
| --- | --- |
| 使用 $build-omnisend-campaign-draft，打开邮件编辑器，我自己操作。 | 打开本地编辑器，你可以选组件、修改内容、预览邮件。 |
| 我要做周年庆邮件，优惠是额外八折，帮我推荐 3 组英文主题和副标题。 | 得到可选的 Subject 和 Preheader 文案。 |
| 把这张参考图做成邮件组件，添加到编辑器里。 | 生成适配 600px 桌面端和 375px 移动端的可复用组件，之后可以在编辑器中选择和使用。 |
| 打开编辑器，指导我把这个 Shopify 商品导入活动商品组件。 | 在支持导入的组件中填写商品链接，点击导入即可填入对应商品信息。 |
| 把这个组件的按钮改成棕色，图片、文案和链接保持不变。 | 按指定范围修改组件，保留其他内容。 |
| 帮我修改这段邮件 HTML，把折扣改成 20%，图片换成这个链接。 | 得到修改后的 HTML，可复制到邮件平台使用。 |
| 指导我把这封邮件保存成模板，再导出 Omnisend HTML。 | 保存可复用模板，并按确认流程完成邮件导出。 |

把活动信息、参考图、HTML 或图片链接一起发给 Agent，并说清楚想改什么即可。具体操作规范已经放在项目文档里，Agent 可以按需读取，不用每次重新说明。
