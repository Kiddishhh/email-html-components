# 移动端首图与六宫格兼容修复设计

## 目标

在不大幅改变 600px 桌面端设计的前提下，修复 Omnisend 375px 移动预览中的首图遮挡感和六宫格左右交错问题。

## 已验证根因

- 首图桌面高度为 722px，移动端受 `min-height:480px` 限制；移动端文案框宽 280px、高约 293px，占首图面积过大。
- 六宫格卡片窄屏堆叠后仍保留 `align="left/right"` 和不对称内边距，造成奇偶卡片左右交错。

## 设计

- 首图最小高度从 480px 调整为 560px；桌面仍由 722px 最大高度控制。
- 首图悬浮框外层水平边距从 24px 调整为 10px；桌面框仍受 `max-width:472px` 控制，移动框可从 280px 扩展至约 308px。
- 六宫格每个包装表格统一为 274px、`inline-table`、无左右 `align`；内部 236px 图片使用 19px 对称边距。
- 桌面端保持两列三行；移动端按 1–6 顺序自然换行为居中单列。
- 不增加媒体查询、Flex、Grid、定位或外部 CSS。

## 验收

- 自动化测试锁定首图 560px 最小高度、10px 水平边距和六张卡片的对称结构。
- 正式 HTML 继续满足静态安全检查并只含一个退订令牌。
- Omnisend Desktop 预览中首图仍为 722px、文案框仍为 472px、六宫格为双列。
- Omnisend Mobile 预览中首图为 560px、标题不再因窄框换成两行，六张卡片横坐标一致且居中。
- Campaign 保持 `draft`，不得调用发送或排期接口。
