# 邮件末尾追加品牌页脚设计

## 目标

在现有“头图 → 六宫格 → 评论整图链接 → 免费礼物 → 地址”组合末尾追加已有 `footer.warm` 品牌信息页脚，并同步更新同一封 Omnisend Campaign 草稿；不得发送或排期。

## 设计

- 页脚继续由 `页脚组件/品牌信息页脚` 独立维护，组合配置只保存完整的内容与设置快照。
- 页脚使用组件当前默认数据、社交链接、背景色和 `[[unsubscribe_link]]` 退订令牌。
- 前五个组件及其顺序、内容、样式保持不变。
- 本地预览继续读取工作区图片；正式 HTML 使用已上传 Omnisend Image Library 的 HTTPS 图片地址。
- 更新 API 前先读取 Campaign 并确认状态为 `draft`；仅替换邮件内容，完成后重新读取并验证仍为 `draft`、包含页脚和退订令牌。

## 验收标准

1. 组合配置组件顺序为六个，`footer.warm` 位于最后。
2. 自动化测试通过，生成 HTML 不含未解析占位符、本地图片路径或禁用标签。
3. 正式 HTML 包含 `[[unsubscribe_link]]`。
4. Omnisend Campaign 状态回读为 `draft`，未调用任何发送或排期接口。
