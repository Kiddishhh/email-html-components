# 公共样式参考（历史存档）

这里存放的三份 CSS **不再被任何组件或构建流程引用**，2026-09-20 整理项目目录时从顶层 `公共样式/` 移到这里，作为早期样式的决策记录保留，便于回查当时的写法。

## 为什么不删

`默认主题-亚麻编辑风.css` 记录了一条仍然有效的设计决策：**实际邮件组件使用内联样式**，不引用外部样式表。这是邮件客户端兼容性的硬约束（Gmail、Outlook 等会剥离 `<style>` 与外链 CSS）。保留这份文件可以避免以后有人重新提出"组件应该共用一份公共 CSS"。

## 为什么不放在顶层

放在仓库顶层会让它看起来像正在使用的共享样式目录。53 个组件各自维护自己的 `component.styles.v1.css` 并内联进模板，顶层不存在共享样式入口。

## 文件

| `移动端适配样式.css` | 早期 375px 移动端适配样式；曾被用作 `htmlCode.style` |
| `默认主题-亚麻编辑风.css` | 默认主题变量草案；文件内已注明组件实际使用内联样式 |
