# 倒计时头图组件设计

## 目标

新增独立邮件组件“倒计时头图”，以参考图的浅色室内背景、居中半透明白色内容面板和单行双区域顶部导航为视觉基准。组件适用于 Omnisend Custom HTML，保持 600px 邮件画布与约 375px 的流式可读布局。

## 边界

- 新组件 Key：`hero.countdownOverlay`；目录：`头图/倒计时头图`。
- 不影响现有 `hero.promotionalOverlay`，也不替换其在既有六组件组合中的位置。
- 使用 table 布局与内联 CSS；不使用 JavaScript、CSS Grid、Flex、绝对定位或外部 CSS。
- “倒计时”是发送前可编辑的静态文本，不按日期实时递减。

## 内容快照

所有字段须在 composition 中显式给出完整快照：

| 区域 | 默认值 | 是否可修改 |
| --- | --- | --- |
| 顶部左文案 | `Unlock $100 Off Your First Order At Freshine` | 是 |
| 顶部右链接文字 | `SIGN UP` | 是 |
| 顶部链接 | `https://freshinelife.com/` | 是 |
| 背景图与 Alt | 使用可替换的图片字段 | 是 |
| 品牌 Logo 与链接 | 促销悬浮首图 Logo 的深色派生图、首页链接 | Logo 固定注入，链接可修改 |
| 装饰分隔图 | 用户提供的线条与菱形 PNG | 固定注入 |
| 倒计时标题 | `Only 3 Days Left` | 是 |
| 补充说明 | `UP TO 65% OFF | Free Gift On $259+ | Free Shipping` | 是 |
| CTA 文字 | `SHOP NOW` | 是 |
| CTA 链接 | 完整 HTTPS URL | 是 |

背景图只承载干净的视觉场景；导航、倒计时、说明和 CTA 都由 HTML 字段渲染，不能烘焙进背景图。品牌使用 `头图/促销悬浮首图/assets/default-logo-white.png` 保持透明轮廓派生的深色 PNG，分隔符使用用户提供的 512×27 PNG，不再以字体或文本符号近似。默认演示注册背景、Logo 与分隔图三项本地资源；最终 Omnisend HTML 中三项都必须替换为公开 HTTPS 图片。

## 结构与样式

1. 组件总画布为 600×751px：顶部只有一条 61px 高导航栏，主视觉背景区为 600×690px。该尺寸将 430×538 参考稿按 `600 ÷ 430` 等比换算后分别计算导航和背景高度，不能再把 751px 总高全部分配给背景区。
2. 背景图片推荐直接上传 600×690px；需要 2× 清晰度时可使用 1200×1380px。比例不一致的图片使用 `cover` 与 `center center`，但准确比例图片不应发生可见裁切或拉伸。
3. 顶部导航栏为一行两区：左侧活动信息区，右侧 `SIGN UP` 点击区。视觉上仍是一条导航栏，而不是两个上下堆叠的导航组件。
4. 主视觉区通过 `<td background>` 与等价内联 `background-image` 展示背景，同时有可读的纯色降级背景。
5. 中央面板为半透明白色，依次包含 120px 宽品牌 Logo、200px 宽装饰分隔图、倒计时标题、补充说明与矩形 CTA。面板最大宽度为 444px，上下内边距为 55px，并以 12/22/35/41px 间距维持参考节奏；在 690px 背景区中垂直居中。
6. 倒计时标题固定使用 `Lora, Georgia, Times New Roman, serif`，默认 67px / 81px 行高；标题文案保持可修改。下方补充文字固定使用 `Montserrat, Arial, Helvetica, sans-serif`，默认 13px / 20px 行高；文案必须支持用户修改。CTA 为 200×43px。
7. `SIGN UP` 区域和 `SHOP NOW` 按钮绑定同一个 `color.theme`。左侧导航色默认按 `35% color.theme + 65% #F4F1EC` 自动计算；默认主题色 `#9D1D20` 对应 `#D6A7A5`。用户可单独覆盖左侧导航色，覆盖后该值不再随主题色自动重算，除非用户要求恢复自动配色。
8. 主视觉区在导航双列之后必须保留 table-cell 默认显示方式，以确保 `colspan="2"` 覆盖完整 600px 画布。窄屏时面板在可用宽度内流式收缩；桌面最大宽度和可读行高保持稳定。

## Skill 自动交互

1. Skill 进入该头图样式时只读取一个主题色：若活动开始时已有全局统一色号，直接使用该色号；否则使用组件默认主题色，并在配置卡中展示。
2. Skill 自动把主题色同时写入右侧 `SIGN UP` 区域和 `SHOP NOW` 按钮，不分别询问两次。
3. Skill 自动计算左侧导航浅色，并在同一配置卡中展示主题色、自动浅色和文字颜色。默认不追加确认问题；用户主动提出时，可单独修改左侧颜色。
4. 配置卡必须展示：600×751px 总尺寸、600×690px 推荐背景尺寸、Lora 倒计时标题、Montserrat 补充文字、当前两段文案、导航链接、CTA 文字/链接及三处颜色应用关系。
5. 用户确认整张头图配置卡后锁定该组件；不为字体、自动浅色或同色绑定分别增加冗余确认。
